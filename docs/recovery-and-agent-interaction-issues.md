## Sizing and order

Each issue is scoped to 30, 45, or 60 minutes **including focused verification**. These are estimates, not claims of completed work. If investigation shows that an issue cannot fit within one hour, split its remaining work before expanding it. A broad full-suite rerun is not required for every localized change.

Follow each issue's linked prerequisites. The plan numbers identify work items; GitHub creation order differs because the central enforcement requirements were published first during the series. Publication of an issue does not authorize retaining a cap, changing live configuration, installing, migrating production data, pushing commits, or tagging.
